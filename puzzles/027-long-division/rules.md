# Long Division — rules

Normal sudoku rules apply: place 1–9 once each in every row, column and 3×3 box.

**Polydivisible lines (purple brackets, invented):** read each line from its dot. For every k, the number formed by the first
k digits along the line is divisible by k. For example, 3816 works on a 4-cell line: 3, 38, 381 and 3816 are divisible by
1, 2, 3 and 4. Digits may repeat on a line if sudoku allows.

**Killer cages:** digits in a cage don't repeat and add up to the small total in the cage's corner.
