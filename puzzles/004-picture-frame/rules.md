# Picture Frame — rules

Normal sudoku rules apply: place 1–9 once each in every row, column and 3×3 box.

**Entropic lines (orange):** any three consecutive cells along an orange line contain one low digit (1–3), one middle
digit (4–6) and one high digit (7–9).
The big square is a **closed loop**: it has no ends, so the triples wrap all the way round. The two short diagonals in
box 5 are two separate 3-cell lines that cross in the centre cell.

**Killer cages:** digits in a cage do not repeat and add up to the small number in the cage's top-left corner.

No given digits.
