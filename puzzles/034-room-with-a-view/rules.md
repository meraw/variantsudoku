# Room with a View — rules

Normal sudoku rules apply: place 1–9 once each in every row, column and 3×3 box.

**Windoku:** each of the four shaded 3×3 windows (rows 2–4 and 6–8, columns 2–4 and 6–8) also contains the digits 1–9
once each.

**Skyscrapers:** each digit is the height of a building. A number outside the grid is how many buildings you can see
from that side, looking along that row or column. A building is hidden by any taller building in front of it.
*Example:* seen from the left, the row 3 1 5 2 9 … shows 3, 5 and 9, so that is three buildings.

No given digits.
