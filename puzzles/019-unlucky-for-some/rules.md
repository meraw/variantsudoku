# Unlucky for Some — rules

Normal sudoku rules apply: place 1–9 once each in every row, column and 3×3 box.

**Every clue in this puzzle is 13.**

**Killer cages:** the digits in a cage sum to 13 and do not repeat within the cage.

**Little killers:** a 13 outside the grid with an arrow gives the sum of the digits along that diagonal. Digits may repeat on a diagonal
where sudoku rules allow it.

**X-sums:** a 13 outside the grid without an arrow (italic: above column 4, right of row 6, below column 1) is an X-sum. Look along that
row or column from the clue. The first digit you see is X, and the first X digits, that one included, sum to 13.
